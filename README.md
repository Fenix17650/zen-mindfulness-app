# Zen Space - Tu Espacio de Mindfulness

Aplicación gratuita en español para respirar, meditar y relajarte en 5 minutos.

👉 **Pruébala en vivo:** https://fenix17650.github.io/zen-mindfulness-app/

## ¿Qué hace?

- **Respiración Consciente:** ejercicio guiado de respiración (5 min)
- **Meditación Básica:** introducción a la meditación mindfulness (10 min)
- **Relajación Matutina:** empieza el día con calma (8 min)
- **Descanso Nocturno:** prepara tu mente para dormir (12 min)

Con temporizador, círculo de respiración y mensajes de final de sesión.

## ¿Para quién es?

Para personas con estrés o ansiedad que quieren una pausa corta durante el día, sin registrarse y sin instalar nada.

## ¿Cómo se usa?

1. Entra al enlace en vivo.
2. Elige un ejercicio.
3. Sigue el círculo: inhala cuando crece, exhala cuando se contrae.
4. Puedes pausar, continuar o finalizar cuando quieras.

Todo funciona en tu navegador, no necesitas registrarte.

## Tecnologías

HTML, CSS y JavaScript. Sin servidor.
